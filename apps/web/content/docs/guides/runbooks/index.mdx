Each alert runbook follows the same shape: Symptom, Impact, Diagnose (read-only commands), Mitigate (changes,
marked as such), Escalate. Every alert email comes from the "RunnerForge Alerts" channel and carries the policy's
display name; each runbook's Symptom section quotes it. For how the alerts are defined, see
[Observability](/docs/design/observability#alert-policies).
